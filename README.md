# Krunker.io Clone 🔫

A browser-based first-person shooter game built with JavaScript and Vite. Inspired by Krunker.io.

## Features

- **First-person shooter** gameplay in the browser
- **Bot AI** enemies with different behavior patterns
- **Weapon system** with multiple weapon types
- **Sound effects** and hit markers
- **Equipment** and power-ups

## Tech Stack

- **Vite** — Build tool
- **Vanilla JavaScript** — No heavy frameworks
- **Canvas API** — Rendering

## Getting Started

```bash
npm install
npm run dev
```

Open the URL shown in the terminal to play.
